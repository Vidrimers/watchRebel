- [ ] 137. E2EE (End-to-End Encryption) для секретных чатов
  
  **Описание:** Шифрование сообщений только в отдельном типе чата — "секретный чат". Обычные чаты работают без изменений (поиск, уведомления с текстом, история на всех устройствах). По аналогии с Telegram: обычные чаты — сервер шифрует, секретные — E2EE, сервер не видит контент.
  
  **Важно: минусы E2EE (только для секретных чатов)**
  
  - Нельзя искать по сообщениям на сервере (поиск только на клиенте)
  - Нет истории на новом устройстве без key backup (если потерял ключ — потерял переписку)
  - Уведомления не могут показывать текст сообщения (только "новое сообщение от X")
  - Нужно генерировать ключи при каждом новом устройстве
  - Невозможно реализовать модерацию контента (убирает возможность борьбы со спамом/абьюзом)
  - Увеличивает размер хранимых данных (зашифрованный текст больше оригинала)
  - Сложность реализации и поддержки (обмен ключами, key rotation, backup)
  - Несовместимость с текущим функционалом поиска по сообщениям и бэкапами
  
  **Стек:**
  
  - Signal Protocol (libsignal-protocol-js) или WebCrypto API (SubtleCrypto)
  - X25519 для обмена ключами (ECDH)
  - AES-256-GCM для шифрования сообщений
  - Хранение зашифрованных ключей на сервере (public keys)
  
  **Подзадачи:**
  
  - [x] 137.1 Генерация ключей при регистрации/логине ✅ 2025-07-26
    
    - Генерация пары ключей (X25519 public/private) — через @noble/curves
    - Публичный ключ отправляется на сервер при регистрации/логине — POST /api/e2ee/keys
    - Приватный ключ хранится в localStorage (никогда не покидает клиент)
    - Проверка наличия ключа в AppInitializer — модалка при отсутствии (137.1.1)
  
  - [x] 137.2 Обмен ключами при начале секретного чата ✅ 2025-07-26
    
    - Создание секретного чата: POST /api/messages/conversations/secret
    - Получение public ключа собеседника с сервера — fetchPublicKey()
    - Вычисление общего секрета — X25519 ECDH (computeSharedSecret)
    - Создание сессионного ключа — HKDF (deriveSessionKey)
    - Сессионный ключ хранится в localStorage (e2ee_session_<conversationId>)
    - UI: кнопка 🔒 в списке друзей, индикатор "Секретный чат · E2EE" в шапке
  
  - [x] 137.3 Шифрование и расшифровка сообщений в секретном чате ✅ 2025-07-26
    
    - Шифрование текста: AES-256-GCM сессионным ключом через WebCrypto
    - Формат: [E2EE]base64(iv):base64(ciphertext)
    - Расшифровка при получении (WebSocket) и загрузке истории (fetchMessages)
    - Превью в списке диалогов: "🔒 Зашифрованное сообщение"

    - Public keys пользователей хранятся в открытом виде — таблица user_keys (137.1)
    - Приватные ключи НЕ хранятся на сервере — только localStorage (137.1)
